📋 Instrucciones de configuración
Paso 1 — Crear el Apps Script
  1. Ve a script.google.com
  2. Clic en + Nuevo proyecto
  3. Borra el código que aparece
  4. Pega el código del Apps Script (ver abajo)
  5. Guarda el proyecto (Ctrl+S) con cualquier nombre
  6. Clic en Implementar → Nueva implementación
  7. Tipo: Aplicación web
  8. Ejecutar como: Yo
  9. Quién tiene acceso: Cualquier persona
  10. Clic en Implementar y autoriza los permisos
  11. Copia la URL de la aplicación web
  12. Pégala arriba en "URL del Apps Script"
Paso 2 — Código del Apps Script
Paso 3 — Publicar el HTML en GitHub Pages
  1. Crea una cuenta en github.com si no tienes una
  2. Crea un repositorio nuevo (ej: alma-monitor), marca "Public"
  3. Sube el archivo alma_monitor.html y renómbralo a index.html
  4. Ve a Settings → Pages, selecciona rama main y carpeta / (root)
  5. GitHub genera una URL tipo https://tuusuario.github.io/alma-monitor
  6. Comparte esa URL con tu equipo — cada quien la abre y sincroniza
